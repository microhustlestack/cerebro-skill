# VESTRIK // VAULT

Deterministic analysis first. Agent reasoning second.

Use the installed `vestrik` CLI for large vaults and structural gap analysis:

```bash
vestrik /path/to/vault --gaps --report vestrik_report.md
```

Surface checkable structural findings: unresolved entities, thin coverage, implicit connections, bottlenecks,
relationship structure, scoring and urgency. Never fabricate a relationship to fill an empty result.
